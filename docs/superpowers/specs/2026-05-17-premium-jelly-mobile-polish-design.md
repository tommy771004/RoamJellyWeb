# Premium Jelly Mobile Polish Design

日期: 2026-05-17
狀態: draft for review
範圍: `HomeTab`、`ItineraryTab`、`ToolsTab`、共享樣式層與共用卡片表現

## 1. 背景

目前介面已具備柔霧果凍感與玻璃層次，但仍有兩個明顯缺口：

1. 部分介面偏向「裝飾完整」而不是「精品細膩」，高光、陰影、字距與按鈕層級還不夠精準。
2. Mobile Web 上不少內容區塊為了維持視覺可愛感，使用了偏厚的留白、較多徽章、較短的摘要與較緊湊的卡片結構，導致正文與關鍵資訊露出量不足。

本次打磨方向採用「精品果凍精修版」：

- 保留柔霧、甜感、奶油色調與果凍材質
- 收斂過度熱鬧的裝飾，改用更精準的材質細節建立高級感
- 在 mobile 優先讓正文與關鍵資訊各多露出一截，必要時犧牲部分裝飾與留白

## 2. 目標

### 視覺目標

- 將整體風格從「可愛玻璃卡片」提升為「柔霧果凍精品介面」
- 讓主要頁面看起來更甜、更柔、更有層次，但不變得幼稚或雜亂
- 提升卡片、按鈕、標題與背景之間的質感一致性

### 內容目標

- Mobile 首屏與列表卡片中，增加可直接閱讀的正文與資訊量
- 降低使用者為了看更多內容而頻繁點開 modal、切 tab、或進入二級畫面的需求
- 讓航班、行程、工具包中的資訊層次更一眼可掃描

### 非目標

- 不改動 API、store、資料模型與業務流程
- 不引入全新頁面結構或全新功能模組
- 不將品牌語言改成插畫貼紙風或極簡工具風

## 3. 設計原則

### 3.1 材質感優先於裝飾感

- 減少大面積炫目色塊與過多 badge 堆疊
- 保留粉、蜜桃、霧藍與奶油白，但改用更淡、更透、更有呼吸感的漸層
- 高級感主要由以下元素建立：
  - 更薄的亮邊與高光
  - 更短更準的陰影層次
  - 更一致的圓角與卡片厚度
  - 更穩定的字級節奏與行高

### 3.2 Mobile 先保內容，再保裝飾

- 內容卡片優先保留標題、關鍵數字、摘要，不優先保留裝飾性標籤
- 允許在手機版收掉重複的副標、降低 badge 數量、縮短裝飾區高度
- 對真正需要資訊完整性的區塊，優先增加文字顯示行數與可掃讀密度

### 3.3 甜感來自節奏，不來自堆料

- CTA 仍保有糖霜感與甜色系，但次級按鈕需要更安靜
- 動效以浮動、漸顯、輕微位移為主，避免浮誇彈跳
- 視覺焦點控制在每個區塊 1 到 2 個，不讓所有元素都同時搶戲

## 4. 影響範圍

### 4.1 全域樣式層

主要文件：

- `src/index.css`
- 可能同步檢視 `src/components/GlassCard.tsx`
- 可能同步檢視 `src/lib/motionTokens.ts`

調整內容：

- 重新校準 jelly 背景的光斑強度與分布，讓背景更像柔焦果凍而不是彩色煙霧
- 微調 glass / jelly / panel / button 的陰影、高光、透明度與邊框亮度
- 新增或調整可供各頁共用的卡片、文字、按鈕、badge 質感 token
- 在 mobile 下降低部分 backdrop blur 與 padding，換取內容可視高度

### 4.2 HomeTab

目標：

- 首屏更像精品旅行入口，而不是資訊與裝飾同時外擴
- 搜尋結果卡與內容推薦卡在 mobile 上看得到更多實際內容

調整區塊：

- 搜尋 hero 區塊
  - 收斂額外裝飾層，提升標題與輸入區的焦點
  - 調整標題、副標、pill 與輸入卡的垂直節奏
- 航班卡片與航班列表
  - 保留目前較成熟的票券感
  - 壓縮非必要空白，讓價格、時間、航空公司資訊更集中
  - 在 mobile 讓次要說明更短，但主資訊更完整
- 精選目的地與達人手帳卡
  - 增加文字露出量
  - 降低封面與 badge 對正文的擠壓
  - 把「可愛感」轉為更像精品明信片的排版節奏

### 4.3 ItineraryTab

目標：

- 行程卡由功能卡提升成精品筆記卡
- 手機上同時看得到更多行程資訊與更好的層次感

調整區塊：

- day toggle 與上方區域
  - 讓 active/inactive 狀態更精緻、更像精品 segmented control
- 行程節點卡
  - 優化卡片表面與資訊區塊分層
  - 降低裝飾性元素對標題、時間、摘要的干擾
  - 在 mobile 增加摘要、地點、狀態等資訊的可視比例
- 編輯與瀏覽狀態的視覺區別
  - 用更輕的材質切換，而不是增加厚重樣式

### 4.4 ToolsTab

目標：

- 工具頁維持旅程延伸層的概念，但更像精品 dashboard
- 卡片資訊更好讀，減少首屏與工具卡之間的樣式競爭

調整區塊：

- 頂部旅程說明區
  - 讓 hero 更穩、更像產品摘要卡，而不是另一個宣傳大卡
- 天氣、checklist、ledger、settlement 各區塊
  - 提升內容密度與排版秩序
  - 讓表單、金額與摘要的資訊分區更乾淨
- 推薦卡區
  - 收掉部分高飽和強對比，避免與主要工具任務搶主次

## 5. Mobile 排版策略

### 5.1 文字策略

- 核心標題維持品牌存在感，但內文與摘要改為更鬆的行高與更穩定的字重
- 手機版摘要文案優先顯示 3 到 5 行，而不是大量 2 行截斷
- 對可掃描資料列使用更明確的主副資訊對比：
  - 主資訊: 較大字級、較深顏色、較緊字距
  - 副資訊: 較小字級、較淡顏色、較高行高

### 5.2 空間策略

- 先縮裝飾區高度、再縮元件間距，最後才壓縮正文區
- 統一降低 mobile 大卡的上下 padding 與 section gap
- 對列表卡優先保留內容寬度，不讓角標、顆粒狀小元件過度侵蝕正文空間

### 5.3 截斷策略

- 僅對次要 metadata、重複說明與補充文案使用較強的截斷
- 核心內容如：
  - 航班時間 / 地點 / 價格
  - 行程標題 / 時間 / 摘要
  - 工具卡數值 / 金額 / 待辦重點
  盡量避免過早截斷

## 6. 元件級設計規範

### 卡片

- 大卡：更柔的內部高光，更窄的外投影，減少厚重感
- 小卡：保持圓潤，但避免每張都有完整舞台效果
- 卡片內部層級應明確區分：
  - 標題區
  - 摘要區
  - metadata 區
  - 行動區

### 按鈕

- 主 CTA：保留糖霜果凍感，但降低色彩噪音，改強材質與亮面
- 次 CTA：從高存在感按鈕改成安靜的精品膠囊按鈕
- icon button：縮減背景重量，避免所有小按鈕都像主角

### Badge / Pill

- 減量使用
- 優先出現在真正有狀態意義的地方
- 裝飾性 badge 若不影響資訊理解，mobile 可減少或合併

## 7. 互動與動效

- 卡片 hover / press 改為更輕的 lift 與 highlight 變化
- 減少過長的彈性 easing，避免界面顯得太玩具化
- mobile 上互動回饋以即時、短促、低位移為主

## 8. 風險與對策

### 風險

- 收掉裝飾後，可能失去原本「一眼覺得可愛」的印象
- 提高資訊密度後，可能讓頁面變得比較像工具而失去品牌感
- 不同頁面若各自微調，容易造成質感不一致

### 對策

- 先從全域 token 與 card/button 語言統一，再做各頁局部細化
- 所有頁面維持共同的奶油粉、蜜桃、霧藍材質規則
- mobile 只收掉不必要裝飾，不收掉品牌色與果凍材質

## 9. 驗證方式

### 視覺驗證

- Desktop 與 mobile 分別檢查首頁、行程頁、工具頁
- 比較改動前後是否更像同一套精品果凍設計系統
- 檢查 dark mode 下文字、邊框與卡片分層是否仍清楚

### 可讀性驗證

- 在 375px 寬度下確認：
  - 首屏敘述文案更容易完整閱讀
  - 推薦卡片正文露出行數增加
  - 航班與行程關鍵資訊不被 badge 擠壓
  - 工具頁摘要與數值區更容易一眼掃描

### 功能驗證

- 搜尋、打開 modal、切換 tab、行程操作、工具表單功能均不回歸
- 不允許因視覺調整破壞現有點擊區、overflow、popup 或 safe-area 表現

## 10. 實作邊界

- 以現有檔案為主進行外觀與排版微調
- 優先修改樣式、className、區塊結構與顯示層級
- 若共用規則重複出現，可抽成少量 shared utility class，但避免大規模重構
- 不在本次範圍內新增新頁、新 store 或新資料流程

## 11. 預期結果

完成後的介面應呈現以下感受：

- 第一眼更甜、更細膩、更像精品旅行產品
- 第二眼更好讀，尤其在手機上能直接看到更多關鍵內容
- 各頁雖然任務不同，但卡片材質、文字節奏與互動氣質更統一
